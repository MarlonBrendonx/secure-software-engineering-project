# Etapa 3 — Vulnerabilidades catalogadas

| Risco | Vulnerabilidade ou categoria                                                                            | Referência utilizada                                                                                                                                                                                                                                                                                                                                                                                                                                       | Relação com o sistema                                                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R01   | Falha na imposição do fluxo de trabalho, que permite alterar um registro fora da sequência de aprovação | [CWE-841](https://cwe.mitre.org/data/definitions/841.html) (Improper Enforcement of Behavioral Workflow), [OWASP Top 10:2025 A06](https://top10.owasp.org/2025/A06_2025-Insecure_Design/) (Insecure Design) e o [Business Logic Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Business_Logic_Security_Cheat_Sheet.html)                                                                                                                  | O perfil analista já escreve nos lançamentos. Se a API aceitar alteração ou exclusão depois do envio, o valor adulterado segue para o ERP sem nova aprovação. |
| R02   | Autenticação de fator único, uma falha de autenticação                                                  | [CWE-308](https://cwe.mitre.org/data/definitions/308.html) (Use of Single-factor Authentication), [OWASP Top 10:2025 A07](https://top10.owasp.org/2025/A07_2025-Authentication_Failures/) (Authentication Failures) e o [Multifactor Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Multifactor_Authentication_Cheat_Sheet.html)                                                              | Phishing ou reuso de credenciais dá a um atacante a conta de administrador ou gestor e, com ela, o controle das aprovações.                                   |
| R03   | Autorização ausente ou contornável pela troca de um identificador (IDOR)                                | [CWE-639](https://cwe.mitre.org/data/definitions/639.html) (Authorization Bypass Through User-Controlled Key), [CWE-862](https://cwe.mitre.org/data/definitions/862.html) (Missing Authorization), [OWASP Top 10:2025 A01](https://top10.owasp.org/2025/A01_2025-Broken_Access_Control/) (Broken Access Control) e o [IDOR Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Insecure_Direct_Object_Reference_Prevention_Cheat_Sheet.html) | Uma rota, um anexo ou uma consulta que confere só o perfil deixa um usuário ler dados de outro cliente ou período ao trocar o identificador na requisição.    |

Estas vulnerabilidades são condições de projeto derivadas dos riscos. Elas não são achados confirmados no código.

As categorias seguem o [OWASP Top 10:2025](https://top10.owasp.org/2025/), versão atual da lista. Em relação à edição de 2021, Insecure Design passou de A04 para A06, Identification and Authentication Failures passou a se chamar Authentication Failures e continua em A07, e Broken Access Control continua em A01.
